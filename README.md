**# MedFlow NutriEco Lite - Version 1.0**



Multi-page medical record prototype with:



\- Role-based access (admin / staff / patient)

\- Wellness \& Eco indices (HLI, EFI, Combined)

\- Supabase Auth, RLS and Storage

\- Admin management with delete functionality

\- Netlify deployment



\## Planned Architecture



\- Clinic-scoped data model

\- Patient portal (self-access)

\- Role-based permissions using RLS

\- Configurable wellness scoring logic
